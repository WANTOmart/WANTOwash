# Folder Gambar

Folder ini berisi semua gambar yang digunakan oleh aplikasi WANTO Wash.

Daftar file:

- logo.png           → Logo WANTO Wash
- no-image.png       → Gambar default jika foto motor belum diupload
- user.png           → Avatar admin/kasir
- banner.jpg         → Banner Dashboard
- motor-default.png  → Gambar motor default
- favicon.ico        → Icon browser

Semua halaman HTML mengambil gambar dari folder ini.
